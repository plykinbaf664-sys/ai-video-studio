# Dry Irony v3: используемые компоненты

- PortraitWindow: окно реального подготовленного источника, геометрия из source/output-постановки, пропорции сохранены. Изменение окна не меняет playback clock.
- SpeechTypography: одна текущая фраза, body/poster/payoff; измерение настоящего Onest, максимум две строки, safe area, проверка лица/клиппинга. Слова развязки добавляются только после наступления своих output timestamps.
- DryIronyV3: авторская постановка трёх реплик, continuous микс с ровным слышимым музыкальным фоном и неизменным голосом, локально подготовленное видео. Никаких phrase ducking/остановки на развязке; pause.* сохранён только как совместимый WAV-алиас. Подложка текста заканчивается перед лицом.

Источники сцены — style-presets/directions/dry-irony-v3.json и src/director/editorial-v3.ts. Это конкретный работающий набор для данного источника; универсальная автоматическая композиция под любое лицо/видео не заявляется. Материалы/шрифты — существующие канонические каталоги. 3D и другие стили сюда не добавлены.
