# Монтажный план и временные шкалы

timeline.ts проверяет и компилирует source/output time, границы слов и поддерживаемые операции. load-edit.ts загружает приватные JSON и связывает их с реальным source.mp4 по хешу.

Текущая DryIronyV3 использует public/generated/dry-irony-v3/edit.json и editorial-v3.ts: 13.8s/414 кадров/22 слова, отдельная уточнённая копия стенограммы. Сохранённые три 15s Reference-композиции используют public/generated/reference-edit/edit.json; для них scene-direction.ts задаёт окно/видимость/крупность, scene-speech.ts — группы речи и раскрытие развязки. Каноническая исходная транскрипция сохранена. Исторический 30s SemanticCut использует public/generated/edit-plan.json. select-style.ts даёт объяснимую рекомендацию по заданной цели. Данные привязаны к SHA-256 исходника и игнорируются Git. Автономного режиссёра или внешних модельных вызовов нет; повторный рендер исполняет существующие решения. Ролевые требования: instructions/editing/, правила Codex — корневой AGENTS.md.
