# Материалы проекта

Источник истины — assets/catalog.json. В библиотеке реально есть Onest/Inter/OFL, четыре mixkit MP3, четыре исходных WAV и SVG. asset-registry.json — только указатель на канонический каталог. Музыкальные условия/происхождение — music/licenses/. Для исходных библиотечных файлов нет автоматического удаления или массового копирования в public.

Контекстные элементы находятся в visuals/<version-id>/: оригинальная вымышленная иллюстрация, описатели трёх нативных схем и provenance каждого файла. Теги/темы/допустимые приёмы/стили — поле visual канонического каталога. Новое назначение или несовместимое изменение шаблона получает новый version-id; использованные версии не перезаписывать. Использование — artifacts/visual-library/usage/, просмотр — artifacts/visual-library/index.html. Команды/условия регистрации — docs/CONTEXTUAL_VISUAL_LIBRARY.md.
