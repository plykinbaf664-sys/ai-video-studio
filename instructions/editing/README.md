# Контракты монтажного процесса

Это инструкции для ролей, которые принимают монтажные решения. Они не являются файловыми инструкциями Codex и не запускают автономных AI-агентов. Разработчик следует корневому AGENTS.md; текущий проход ролей авторуется Codex и исполняется детерминированным кодом.

Порядок: [режиссёр](director.md) → [визуальный дизайнер](visual-designer.md) + [звук](sound-editor.md) → [QC](qc-reviewer.md) → пересмотр. Каждая роль выдаёт конкретные данные/решения с источником, не общую оценку «красиво/динамично».
