# QC: два отдельных решения

Технический QC проверяет фактический готовый MP4 и его SHA: длительность/потоки/полное декодирование, source/output, целые слова, звук/изображение, сохранение голоса, музыку и уровни, повторное ASR. ASR ошибки и неуверенность перечислять для ручного прослушивания; не исправлять речь по одному распознаванию.

Визуальный QC проверяет кадр целиком, лицо/жесты/предметы, safe zones, число текстовых слоёв/строк, обрезание, контраст/масштаб, уместность сцены/анимации/паузы и соответствие конкретному референсному приёму. Проверить, что три варианта не являются одной композицией с перекрашенной плашкой.

Выход: доказательства, конкретные дефекты и повторная проверка исправлений. Не писать «профессионально/утверждено» по одному зелёному тесту. Полноэкранный graphic cutaway учитывать как намеренную замену видимой картинки; не выдавать его за 100% совпадение видимых исходных кадров.

V3 добавляет source-acoustic refinement короткого «И» только в отдельной копии стенограммы: source 38.52s по подъёму исходного сигнала, output 9.32s; evidence находится в режиссёрском JSON и audio-mixes.json. Это оценка начала по акустике, не человеческая фонетическая разметка. ASR по-прежнему может относить предшествующий тихий участок к слову. Для локального grade сравнивать ожидаемые исходные пиксели с учётом заявленного профиля; не снижать порог корреляции ради красивого отчёта. Результаты loudnorm использовать как измерения входа, не выдавать отброшенный нормализованный выход за реально применённый мастеринг.

Новый job-путь хранит доказательства в artifacts/jobs/<id>/, отдельно от исторической V3. Ожидаемое число кадров/слов берётся из задания, не фиксируется как 414/22. Для dry-irony-story это 930/40; уточнения ранних начал «Я», «Сам», «Потому», «И» опираются на source-only RMS и остаются кандидатами. Не считать ранний start финального ASR доказательством раннего произнесения при тихом preroll. Неразрешённые лексические расхождения блокируют выдачу без hash-bound evidence review; даже с доказательствами сохранности waveform статус ASR review-required остаётся видимым. Кадры галереи извлекать из фактического MP4. Текущий local runtime с junction public/ не является переносимой сборкой для публикации.
