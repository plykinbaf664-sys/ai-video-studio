# Звукомонтаж

Вход: оригинальный голос, реальные зарегистрированные MP3/WAV, source/output mapping, паузы и смысловая развязка.

Выход: конкретная дорожка и исходный участок, один стабильный gain музыкального фона, короткие плавные края, микс с запасом по уровню. По явному предпочтению пользователя музыка должна быть слышна, не мешать голосу и не скакать. По умолчанию запрещены phrase ducking, подъём музыки между фразами и остановка ради развязки. Голос и порядок слов сохраняются, не обрезаются для удара бита. Темп/спектральные onsets — вспомогательная оценка; не считать автоматический BPM музыкальной гарантией.

Фон продолжается через паузы и финал на том же gain. Другое поведение — только по новому явному запросу пользователя. Уровень выбрать один раз по всему участку, проверяя запас относительно тихих сохранённых слов. Лицензии/происхождение указывать реально, не выдумывать квитанции. QC проверяет голос после вычитания известной подложки, а не только корреляцию всего микса; постоянство gain измеряет по фактическому PCM относительно исходной музыки. Естественные удары/фразировка музыки сохраняются; измерения не выдавать за ручное прослушивание.
