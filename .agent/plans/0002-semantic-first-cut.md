# Первый смысловой монтаж

## Цель и границы

Пользователь разрешил следующий этап после первого технического MP4: расшифровка с таймкодами → обоснованный edit plan → осмысленный ролик. Сохранить FirstTest и исходник. Не реализовывать библиотеку 20 стилей или автономный Auto Director.

## Проверенные факты

- public/source.mp4: 53.7537 с, 720×1280, около 59.94 fps, оригинальный звук.
- out/first-test.mp4 технически проверен, содержит исходник и нейтральный титр.
- Remotion 4.0.537; контракт contracts/edit-plan.schema.json (draft 2020-12).
- Python 3.10 установлен, faster-whisper не установлен.
- GPU Intel HD Graphics 3000; выбирается CPU-адаптер распознавания вместо требующего современной GPU whisper-webgpu.
- Видео/голос не отправлять внешнему провайдеру. Разрешено скачать локальный движок/модель; данные остаются на компьютере.

## Предпочтение результата

Пользователь выбрал компактный ролик 30–40 секунд. Сделан вариант 30 секунд с сохранением всех шести реплик и исходного порядка.

## Шаги

- [x] Изолированный локальный CPU-движок, реальная расшифровка с таймкодами 40 слов и хешем.
- [x] Schema, границы, две временные шкалы, хеш и тесты склеек. 7 тестов passed.
- [x] План 6 фрагментов с причинами; сохранены все распознанные слова и порядок, у графики есть evidence/purpose.
- [x] SemanticCut: общая Sequence для изображения, оригинального звука и source captions.
- [x] ESLint/TypeScript, Studio, кадры 30/180/870, MP4 с полным декодированием, 12 waveform-проверок passed.

## Критерии

Транскрипт и edit plan реальны, локальны и сериализованы; source/output time не смешаны; нет обрезанных слов на выбранных склейках; видео и оригинальный звук сдвигаются вместе. MP4 существует, декодируется целиком; неизвестное качество распознавания/слуховой проверки сообщается честно. Первый технический MP4 сохраняется.

## Результаты / неизвестные

Результат out/semantic-cut.mp4 (30 секунд) и out/semantic-cut.verification.json созданы. CTranslate2 4.8.3 аварийно завершался на этом CPU; 4.4.0 отработал с моделью small, закреплён в requirements-transcription.txt.

Текущий процесс assisted: план составлен Codex, повторный рендер не выбирает смысл автоматически. ASR остаётся черновиком с low-confidence словами; требуется слуховая редактура и оценка комических пауз. Waveform совпал с исходными временами всех клипов, лаг 0 ms в 12 окнах с шагом поиска 1 ms; это не подтверждение каждого слова на слух.
