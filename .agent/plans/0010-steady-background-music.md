# Ровная фоновая музыка

Требование пользователя: музыка слышна фоном, не перекрывает голос, без скачков громкости и остановки перед финалом. Изображение/монтаж/субтитры не изменять. Предыдущая V3 с паузой сохранена в artifacts/dry-irony-v3/music-before-steady/.

- [x] Постоянный gain музыкальной дорожки; без phrase ducking/подъёма в паузах. Короткие плавные края только в начале/конце файла.
- [x] Подобрать один уровень по реальным голосу/музыке; измерить разницу для каждого сохранённого слова. Проверить отсутствие автоматизации gain вне краёв.
- [x] Обновить Studio и воспроизводимый preset; закрепить пользовательское предпочтение в инструкциях звукомонтажа.
- [x] Заменить только аудиопоток MP4, доказать идентичность H264-пакетов/таймкодов. Полное декодирование, исходный waveform, независимое ASR, пики/громкость.
- [x] Обновить галерею/отчёт и выдать проверенный MP4. Непрерывное человеческое прослушивание не имитировать.

## Реально выполнено

Готовый out/dry-irony-v3-steady.mp4: 10957572 байт, SHA-256 6633795ab024f45b425cf1451977cae91832750c18968b8baacdf2396350c126. Видео 1080x1920/30fps/414 кадров/13.8s H264, AAC48k. verify-video-copy подтвердил идентичность всех H264 пакетов и таймкодов. Полный decode, 414 кадров, 56 аудиоблоков, 22 слова waveform, independent final ASR 22/22 без lexical errors. Автоматизации gain вне краёв нет; измеренная вариация 0.000139dB, запас голоса на каждом слове не менее 14.00dB RMS. Это не ручное прослушивание и не подавление естественного музыкального ритма.

Галерея/QC обновлены, прежний MP4/профиль/отчёт сохранены. Основной Studio использует continuous.mix.wav с cache key нового музыкального правила; инструкция звукомонтажа и AGENTS закрепляют предпочтение пользователя.
