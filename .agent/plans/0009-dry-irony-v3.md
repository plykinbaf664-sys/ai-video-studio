# Dry Irony v3 — доведение одного ролика

## Цель
Пользователь принял предложение: улучшить драматургию, размер ведущего, графическую сдержанность, звук и локальную коррекцию лица. Сделать отдельный проверенный MP4, сохранив три предыдущих варианта и оригинал. Никакой разработки 20 стилей/автономного режиссёра.

## Порядок и доказательства
- [x] Проверить исходные реакции/паузы; отдельный source/output план без потери 22 слов.
- [x] Подготовить контрольные кадры before/after для мягкой коррекции лица и шесть кадров раскадровки до полного рендера.
- [x] Реализовать увеличенное редакционное окно, крупные произнесённые фразы, полноэкранный финал; убрать micro-labels. Выделить используемые компоненты в src/design/editorial/.
- [x] Подготовить два музыкальных решения с одинаковым голосом: continuous / pause. Основной кандидат — pause перед финальной репликой, по драматургическому основанию; не заявлять несуществующее слуховое прослушивание.
- [x] Выполнить новый рендер, полный decode, source/output/каждый кадр и слово/waveform, независимое локальное ASR, sample peaks и дополнительные измерения громкости.
- [x] Проверить реальные финальные кадры, сохранить отчёт/галерею/сравнение v2↔v3; обновить точку входа и инструкции.

## Ограничения
Референсы/музыка/брендбук уже доступны. Приватные медиа остаются локальными. Никакого удаления/перезаписи старых MP4 и исходных данных. Точная длительность определяется целыми фразами и реакцией; исходная сравнительная 15s нарезка остаётся отдельно. Фиксированные мягкие маски коррекции — ручная настройка этого источника, не автоматическое распознавание кожи/лица. Техническая синхронизация не равна художественному утверждению или ручному прослушиванию.
