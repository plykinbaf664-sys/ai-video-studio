# Аудит проекта и переделка монтажа по видео-референсам

## Запрос и критерий
Пользователь отверг три предыдущие версии как визуально одинаковые. Нужны аудит фактического проекта и новых видео/музыки, устранение противоречий, разграничение инструкций Codex и монтажных ролей, затем реальный монтаж по разобранным приёмам. Не считать technical QC доказательством художественного качества. Исходники/пользовательские материалы сохранять; прежнее удаление out/ не согласовано, не выполнять.

## Проверенные факты
- В reference-library/media/video/ лежат IMG_3320.MP4 (124.2s), IMG_3321.MP4 (172.8s), IMG_3322.MP4 (51.63s). Прежние документы о нулевых видео устарели.
- Четыре реальных Mixkit MP3 имеют исходные названия mixkit-*.mp3; документация/registry искали придуманные другие имена и утверждали отсутствие файлов.
- AGENTS.md устарел; baseline-ограничения ошибочно описывают весь продукт. В рендерере три варианта разделяют нарезку, крупность, маленькую верхнюю карточку и большую часть сцен. Различия не сопоставлены с измеримыми признаками видео-референсов.

## Шаги
- [x] Инвентаризация и разбор всего видеоматериала: хронометраж, сцены, типографика, графические приёмы, движения, звук; конкретные таймкоды и кадры.
- [x] Проверить музыку, реальные имена/лицензии/темп/огибающую; подключить уместную дорожку с ducking и headroom.
- [x] Свести актуальные документы в единую точку входа; исторические пакеты/отчёты маркировать отдельно; отделить роли разработчика от контрактов монтажного процесса.
- [x] Устранить архитектурные причины одинаковости: сценический план, крупная типографика, мотивированная смена композиции, реализованные компоненты, музыка/пауза и переходы с объяснимой функцией.
- [x] Проверить на реальных кадрах, пересобрать MP4 и выполнить source/output, waveform, ASR, кадры/safe zones и уровни.
- [x] Сдать новый ролик, кадры, фактический аудит и актуальный мануал; художественные возможности и ограничения назвать честно.

## Решения
Не размножать три почти одинаковые карточки. Сначала один законченный ролик с убедительной сценической режиссурой по референсам; три исходных отклонённых экспорта сохранить как историю. Объём остальных реально различающихся пресетов определить после анализа материала и общего сценического контракта.

## Фактический результат

Созданы и проверены все три существенно отличающихся 15s варианта: out/reference-{editorial-focus,signal-dynamic,dry-irony}.mp4. Контрольные кадры фактических MP4 просмотрены и привязаны к SHA-256. Все 22 слова/60 аудиоблоков/450 кадров проверены, отдельные ASR boundary review items сохранены. Художественное утверждение пользователем остаётся pending.

Аудит/исправления: docs/PROJECT_AUDIT.md, docs/REFERENCE_AUDIT.md; финальный QC: docs/REFERENCE_EDIT_QC.md; исходный manifest 56/56, npm lint/test 26/26, design/context/validate:edit/audit:out, Studio/main bundle пройдены. Старое ядро и пользовательские оригиналы сохранены. Переносы без удаления.

Уточнение решения: после проверки сценического контракта реализованы все три исходно запрошенные версии. Различия затрагивают окна/крупность/графические сцены/иерархию/музыку/остановки, а не только цвет. Независимые проверки не выдаются за художественное одобрение. Текущие ограничения и ручные проверки перечислены в финальном QC.
