# Стилевые контракты

runtime/ содержит baseline и три исполняемых сценических personal-направления. Поле staging действительно задаёт сцены, смысловые задачи, референсы и музыку. src/design/stages/ исполняет их. Три направления candidate до художественной оценки пользователя.

20 JSON в корне — неисполненные проекты. archive/personal-v1/ — отклонённый первый визуальный пакет; archive/design-kit-specs/ — первоначальная спецификация. Они не определяют текущий Studio. Проверка: npm run design:check. Полные правила: docs/STYLE_SYSTEM.md.
