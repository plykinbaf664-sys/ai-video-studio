# Аудит проекта и исправления — 23 октября 2026

Снимок прохода 0008 до доведения V3. Текущая доработка — docs/DRY_IRONY_V3_QC.md, план 0009; описанные ниже три сравнительных MP4 сохранены.

## Причины слабого результата

1. Три названия стиля исполняли почти одну сцену. Стиль ограничивался небольшой текстовой карточкой, тогда как видео-референсы используют смену композиции, отдельные типографические сцены и графические шаги.
2. Реальные IMG_3320/3321/3322 не были отражены в текущем каталоге и инструкциях. Старые документы одновременно содержали новые статусы и прежнее «материалов нет».
3. Четыре MP3 существовали под mixkit-именами, но документы/реестр искали переименованные отсутствующие файлы. Музыка не участвовала в драматургии.
4. QC подтверждал техническую корректность, но не проверял, стали ли три направления различаться по сценам. Техническое passed ошибочно воспринималось как художественное утверждение.
5. Рабочие JSON/WAV/PNG/скрипты попадали в out/. Несколько путей входа в Studio, архивные инструкции рядом с актуальными и дублирующие asset registries мешали определить источник истины.

## Что исправлено в реализации

Существующие timeline/source-output/проверки речи сохранены. Сверху добавлены scene-direction.ts, scene-speech.ts и src/design/stages/: явные layout/from/purpose, крупность/видимость, реальная цитата с источником, отдельная графическая сцена, типографика с измерением строк и защитой лица. Три профиля runtime действительно выбирают разные renderer/сцены/музыку. Подложки подготовлены из предоставленных MP3 с ducking и паузой. Общий source-specific SDR-кэш сохраняет реальную карту исходных PTS; оригинал не меняется.

Результаты: out/reference-editorial-focus.mp4, out/reference-signal-dynamic.mp4, out/reference-dry-irony.mp4. Параметры/хеши/ASR/неопределённости: [REFERENCE_EDIT_QC.md](REFERENCE_EDIT_QC.md). Сравнение — artifacts/reference-edit/index.html и comparison.png. Реальные зависимости подтверждены npm ls --depth=0, версии Remotion согласованы 4.0.537; новые внешние библиотеки не добавлялись.

## Что нужно для следующего качественного шага

Референсы, музыка, шрифты и брендбук уже есть. Следующая задача — художественно выбрать основное направление на этих трёх роликах и довести небольшой набор сцен под реальные смысловые задачи: сравнение, процесс/связи, цитата, доказательство. Для каждого блока нужны назначение, конкретные reference beats, адаптивная композиция, анимационное поведение, звуковая политика и реальные примеры использования. После этого связывать выбор блока с смысловым edit plan.

Не требуется закупать случайную коллекцию эффектов или объявлять 20 текстовых описаний готовыми стилями. Для нового фактического доказательства нужны собственные материалы/данные; для настоящего 3D — конкретная разрешённая модель/сцена и отдельная реализация. Здесь используются оригинальные SVG/CSS-композиции. Цветокоррекция описана в COLOR_WORKFLOW.md; ограничение исходного света/пересветов не маскируется названием «cinematic».

Алгоритм выбора сейчас объяснимый и ограниченный: явный styleId либо рекомендация по заданному intent. Автоматического понимания нового видео и самостоятельного AI-режиссёра пока нет. Код рекомендаций и различие manual/recommendation описаны в STYLE_SYSTEM.md. Следующий этап не должен начинаться с расширения количества пресетов при недоведённых сценических компонентах.
