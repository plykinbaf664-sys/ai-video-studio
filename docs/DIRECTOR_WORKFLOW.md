# Режиссёр: Qwen, локальная проверка и передача в монтаж

Реализованы подготовка задания, строгий формат двух замыслов, проверка и компиляция выбранного плана в существующий EditorialJob, локальное сравнение и передача в Studio. Подключён реальный облачный текстовый Qwen: docs/QWEN_SETUP.md. Первый ответ получен25.10.2026, но план не прошёл QC без локальной редакторской доработки; docs/QWEN_FIRST_RUN.md. Генерация требует настроек, ключа и подтверждения точного текстового payload. Автономное профессиональное качество и анализ интонации/жестов не заявляются по одному ответу.

## Что получает режиссёр

`director:prepare` читает реальный исходник, текущий job и исходную стенограмму с отдельными акустическими уточнениями. Он фиксирует SHA исходника, плана, транскрипта, пресета, каталогов и инструкций. Проверяются фактические файлы, лицензии и хеши ассетов/референсов. Создаются три реальных исходных кадра на каждый разрешённый фрагмент, с requested/actual source PTS и SHA; оригинал доступен локально для просмотра/прослушивания. Извлечение кадров не считается анализом движения, эмоций или интонации.

Запрос приватный: `artifacts/director/<run>/request.json`, кадры `evidence/`. Сеть не используется. Пакет содержит цель, явно неизвестную аудиторию, слова со стабильными в пределах запроса ID, исходные монтажные единицы, конкретные reference beats, брендбук, допустимые ассеты и перечень отсутствующих возможностей. Hash привязывает ответ к этому конкретному контексту. Изменение исходника, инструкции, монтажного ядра или библиотеки требует нового run.

Первая версия выбирает/переставляет **существующие проверяемые исходные фрагменты**; произвольную новую границу нарезки по предположению модели не принимает. По умолчанию вся речь из этих фрагментов обязательна. Слова вне этой выборки перечислены отдельно в coverage.unavailableWordIds. Сокращение слов разрешается только новым заданием с явным `--allow-omissions`; каждое исключение получает причину. Это ещё не автоматическое определение безопасных новых склеек по произвольному видео.

## Выход и проверка

Контракт: `contracts/director-response.schema.json`; смысловой компилятор: `src/director/semantic-director.ts`; инструкция роли: `instructions/editing/director-system.md`. Ответ содержит два существенно разных замысла, главную мысль, эмоциональный ход, блоки реальных реплик, сцены, доказательства из слов, референсные интервалы, производственные потребности и риски. Текст субтитров и произвольные пути/код/цветовые/звуковые настройки в ответе запрещены.

- Все монтажные единицы учтены: оставлены однократно или исключены с причиной. Реплика, существование цитаты, сохранность контекста и юмора — разные вопросы; последний требует просмотра.
- Сцены привязываются к началу сохранённого фрагмента или окончанию конкретного слова с subtitle tail. Только итоговая шкала. Числовые source/output координаты вычисляет существующий timeline, а не модель.
- Проверяются происхождение всех слов, безопасные склейки, паузы, порядок/длительность сцен, настоящие интервалы референсов, сохранность лица, раннее раскрытие цитат и минимальное время их чтения. Оформление, source-specific цвет и тихая непрерывная музыка наследуются из задания.
- Переименование плана или небольшой сдвиг тайминга не считается вторым замыслом. Должны отличаться отбор/порядок реплик либо структура сцен/цитат. Это структурный критерий; художественную разницу оценивают просмотром.
- Недостающие diagram/3D/icons/B-roll/автоцвет/face tracking записываются как задачи с опорой на речь и существующей сценой для исполнения сейчас. Новый ресурс или эффект не подставляется случайно.
- Статус корректного плана: `plan-validated-media-unreviewed`. Self-review модели не заменяет проверки готового MP4, waveform, повторного ASR и человеческой оценки.

## Команды

Подготовить новое задание (run не перезаписывается):

```powershell
npm run director:prepare -- --run my-director-run --job dry-irony-tight
```

Можно передать `--objective "Цель ролика"` и `--audience "Для кого ролик"`. Если аудитория не задана, она остаётся неизвестной. Ничего не отправляется провайдеру.

Проверить локальный ответ, соответствующий schema и contextSha256:

```powershell
npm run director:review -- --run my-director-run --response artifacts/director/my-director-run/response.json
npm run director:select -- --run my-director-run --response artifacts/director/my-director-run/response.json --treatment chosen-id
npm run director:stage -- --run my-director-run
```

`review` сохраняет ответ и отчёт в `revisions/<response-sha>/`; HTML показывает слова, цели, реальные исходные кадры, шкалу сцен и нерешённые вопросы. Все строки ответа экранируются; страница не выполняет код и не загружает удалённые ресурсы. `select` создаёт новый `edits/<run>-<treatment>.json`, не заменяя текущий job. Повторный выбор требует нового run. `stage` повторно проверяет привязки, готовит реальное видео/звук и раскадровку теми же скриптами, затем переключает отдельную композицию Studio:

`http://localhost:3001/DirectorPreview` (`npm run studio`, если Studio ещё не запущен).

До первого выбора DirectorPreview показывает существующий DryIronyTight. Исходная композиция DryIronyTight и default render остаются прежними. Stage не рендерит MP4 и не присваивает художественное одобрение. Отдельный экспорт выбранного задания:

```powershell
node scripts/render-editorial-job.mjs --job my-director-run-chosen-id
```

Экспорт проходит существующий полный QC и только затем попадает в out/. Старый проверенный MP4 не заменяется.

## Реальный контрольный пример без провайдера

`director:example` работает исключительно на dry-irony-tight. Он явно переносит существующие ручные решения в контракт и добавляет вариант с приоритетом говорящего (две сцены вместо семи). Все40 слов взяты из исходной стенограммы, новых субтитров нет. Authorship: baseline-adaptation; это контроль интеграции, не AI-анализ или новое художественное утверждение.

```powershell
npm run director:prepare -- --run director-offline-001
npm run director:example -- --run director-offline-001
npm run director:review -- --run director-offline-001 --response artifacts/director/director-offline-001/authored-response.json
npm run director:select -- --run director-offline-001 --response artifacts/director/director-offline-001/authored-response.json --treatment performance
npm run director:stage -- --run director-offline-001
```

Если этот run уже есть, выбрать новое имя для всего набора команд. Нельзя использовать пример для чужого исходника.

## Позже: подключение провайдера и критерии приёмки

Граница провайдера — src/director/provider.ts; реальный Node-only Qwen transport — scripts/lib/qwen-provider.mjs и qwen-workflow.mjs. Подготовлено подключение Alibaba Cloud Model Studio, docs/QWEN_SETUP.md; ключ/регион/модель пользователь задаёт позднее. provider-check и preflight не делают API-вызов. generate требует подтверждения конкретного текстового payload и не отправляет медиа. Для будущего анализа кадров/аудио/видео потребуется отдельное согласование состава/лимитов и фактическая реализация модальности. Одна регистрация ключа не заменяет согласие на отправку приватных материалов.

Следующий сквозной тест: настоящий провайдер предлагает два плана по тому же запросу → проверка → раскадровка → сравнение с текущим ручным монтажом → MP4/QC → другой реальный исходник с собственной стенограммой, безопасными фрагментами, лицевой областью и цветом. Принимать по сохранённой мысли, естественной речи, уместности сцен, читаемости и авторской подаче. Прогноз удержания/виральности без реальных данных не заявляется.
