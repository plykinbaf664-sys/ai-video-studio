# Сценическая режиссура стиля

Фактическое число реализованных стилей — **3**: Editorial Focus, Dry Irony, Signal Dynamic (три runtime-профиля и три грамматики). baseline-unbranded — техническая база. Описательные draft-пресеты, Tight/Story/V3, visual A/B и context-domestic-001/002/003 не прибавляют новых стилей. Ни одна новая кандидатная версия не получает художественное одобрение автоматически. Текущая раскадровка ведущего0019: [PRESENTER_FRAMING.md](PRESENTER_FRAMING.md).

В0016 добавлены исполнительный SignalInfographics и три ограниченные Visual Understanding policy/grammar. Для A/B выбран Signal Dynamic: последовательная смысловая графика сверху по IMG_3322:14.3–19.3/26.3–31.2, ведущий снизу, возврат к полному кадру на развязке. `SignalInfographics.tsx` — новый кандидат; графика следует проверенным source excerpts и reveal frames. Реальный image-анализ выполнен после отдельного разрешения: в B увеличивается видимая область человека/рук/планшета, без новых цитат/зумов/эффектов. Лицо становится меньше; это технически консервативное решение, не автоматическое художественное улучшение. Во всех новых вариантах музыка steady; старые ducking/stop в исторической таблице ниже не наследуются. Подробнее docs/VISUAL_UNDERSTANDING.md.

Один стиль — набор решений по ритму, крупности, композиции, типографике, графике, анимации, звуку и переходам. Отличие одного цвета карточки недостаточно.

После сравнения пользователь согласовал доведение Dry Irony. Текущая v3: увеличенное окно ведущего, крупные произнесённые фразы, сокращённые паузы и полноэкранная развязка. Последующее явное предпочтение по звуку: музыка непрерывным слышимым фоном на одном gain, без приглушения по фразам/подъёма в паузах и остановки. Конкретная постановка — style-presets/directions/dry-irony-v3.json; это версия существующего направления. Три runtime-профиля ниже и исходные сравнительные MP4 сохранены как история. Финальная художественная оценка v3 остаётся отдельной.

Историческая цитата в схеме отдельно помечена как context quote и имеет источник в уже услышанной речи.

Настоящая 3D-сцена не заявляется по 2D-свету/перспективе; референсные карточки могут быть реализованы обычной сценографикой.

Первые v1-результаты отклонены: artifacts/history/personal-v1. Их технические отчёты не являются визуальным утверждением. Текущие три направления до пользовательской оценки — candidate.

## Как выбирается стиль

В Studio выбор явный: Reference-editorial / Reference-signal / Reference-paper. Сравнительный рендер создаёт все три. src/director/select-style.ts уже возвращает объяснимую рекомендацию по заданному intent: story → Editorial, explanation → Signal, irony → Dry Irony, либо принимает конкретный styleId. Проверяет совместимый брендбук и доступность стиля; не выдаёт candidate за approved. Сейчас этот helper не слушает видео и не запускает автоматический выбор при рендере: смысловой intent и сценический план заданы явно. Для текущей иронической реплики наиболее естественен Dry Irony; Signal показывает возможности графической подачи, но простая бытовая мысль не требует сложной 3D-схемы.

Текущий проход отделяет Dry Irony от конкретного клипа: style-presets/grammars/dry-irony.json + задания edits/. Четыре компонента в src/design/scenes/: говорящий, крупная текущая речь, split-перечень и сравнение реальных цитат; полный кадр — вариант говорящего. Грамматика управляет типографикой, группировкой/анимацией текста, набором сцен, ритмом, переходами и steady music policy; конкретное назначение сцен пока ручное. Цитата требует диапазона сохранённых source words и ждёт завершения речи. 31s задание и рабочие команды — docs/REUSABLE_EDITING.md, фактические проверки — artifacts/jobs/dry-irony-story/. Это существующий Dry Irony, не дополнительный стиль. Следующий шаг после оценки — связать выбор сцен со смысловым планом. Случайная библиотека из сотен иконок не решает проблему режиссуры. Для настоящего 3D понадобятся конкретная сцена/модель/материалы с правами и выделенный компонент; сейчас реализованы SVG и CSS-композиция, а не 3D-движок.
# Контекстные компоненты (0017)

Уточнение0018: для бытовой иронии пользователь предпочитает естественные фотографические семейные сцены, а не рисованный AI-вид. Подходящая серия действий получает разные фото и мотивированную смену масштаба, включая короткую cutaway; финальная реплика возвращается к лицу. Это переносимое правило domestic-counterpoint-v1 с явным brief, не «картинка на каждую фразу» и не правило для AI-объяснений. Реализация и границы — [DOMESTIC_PHOTO_STORY.md](DOMESTIC_PHOTO_STORY.md).

Схемы process/comparison/system и версии иллюстраций выбираются по редакторской задаче, а не случайной частоте. Компоненты наследуют palette/typography/motion из существующих Editorial Focus, Signal Dynamic, Dry Irony; это не новые стили. Бытовой contrast допустим для domestic/general, AI explanation — через подтверждённые узлы/связи. VisualLibraryLab показывает компоненты на всех3 грамматиках; художественное принятие будущего монтажа не следует из этих9 кадров. Контракт — docs/CONTEXTUAL_VISUAL_LIBRARY.md.
