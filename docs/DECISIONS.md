- Visual Understanding0016 расширяет существующий транспорт реальными timestamped JPEG и source/output evidence; raw video/audio остаются локально. Image-запрос требует отдельного явного разрешения на точное тело. В A/B фиксируются один стиль Signal Dynamic, речь, нарезка, цвет и PCM-микс; менять можно только обоснованную изображениями геометрию/наличие графики. Sparse samples не заменяют трекинг. Низкая confidence сохраняет ручной fallback; ничем не оправданный зум запрещён. docs/VISUAL_UNDERSTANDING.md.

- Разделить общий монтажный clock и сценическую режиссуру. Причина: первый пакет имел одинаковые сцены и лишь менял маленькую карточку; пользователем отклонён. Новый renderer исполняет сцены и музыку, не только палитру.
- Сохранить source/output ядро и существующую расшифровку. Словные уточнения personal-выборки хранятся отдельно; оригинал и каноническая стенограмма не переписываются ради дизайна.
- Один Studio и единый каталог каждой библиотеки. Старый Design Kit — архив происхождения, не параллельная активная конфигурация. Исторические регистры не должны спорить с assets/catalog.json.
- Музыка уже предоставлена пользователем. Реальные имена/хеши и текущие Mixkit-условия записаны. CDN 403 не выдаётся за совпадение бинарных файлов; происхождение обозначено честно, локальное использование соответствует запросу пользователя.
- Общий 15s видеокэш готовится один раз для трёх направлений, чтобы не повторять цветокоррекцию на 8GB машине. Frame map связывает его с неизменённым source.
- Ничего не удалять при реорганизации. Исходники и старые монтажные данные сохраняются; перемещения фиксируются в artifacts/project-audit/file-moves.json. out/ хранит только готовые видео.
