# AI Video Studio — Personal Design Kit v1.0

**Дополнение к существующему проекту** `ai-video-studio`, а не замена проекту. Распаковать содержимое архива в **корень существующего проекта**, сохраняя пути. Существующие `AGENTS.md`, `docs/`, `style-presets/*.json`, `src/index.ts`, `src/Root.tsx`, `package.json` не заменять.

## Что реально подготовлено
- 1 предложенная визуальная идентичность для экспертного личного блога об AI, маркетинге, бизнесе, личных историях.
- 3 разных режиссёрских пресета (Editorial Focus, Signal Dynamic, Dry Irony), связанные одним брендбуком.
- Реальные React/Remotion-компоненты для типографических сцен, смыслового маркера и субтитров.
- 3 Remotion preview-compositions с **одинаковым текстом**. Это работающие исходники для интеграции и тестового рендера, но не доказательство рендера в вашем локальном репозитории.
- 15 пользовательских скриншотов-референсов с описаниями; **это не видео**, таймкоды, движение и звук не верифицированы.
- 4 самостоятельно синтезированных ненавязчивых SFX WAV с происхождением; список лицензируемой музыки, которую необходимо скачать у правообладателей отдельно.
- Реестр исходников, лицензий и инструкцию по подключению.

## Ограничения
**Не** включены: чужие оригинальные Reel-видео, временные коды монтажных приёмов, профессиональные музыкальные файлы со стоков, бинарные файлы шрифтов, фирменный утверждённый логотип, действующий монтаж пользователя. Локальный проект Codex не подключён и не обследован. Реальные параметры и рендер проверяет Codex на вашей машине.

## Где что лежит
- `brandbooks/media/` — описания бренда, палитра, типографика, сигнатурный графический элемент.
- `reference-library/media/` — screenshots + разборы и анализ конкретных элементов.
- `assets/library/` — реестр ресурсов, исходные SFX, векторные графические исходники, ссылки на проверенные поставщики музыки и шрифтов.
- `style-presets/personal-*.json` — три сценарных режиссёрских пресета, без перезаписи старых 20.
- `src/design/` — компоненты для интеграции с Remotion и отдельный entrypoint для превью.
- `scripts/sync-design-assets.mjs` — копирование разрешённых локальных активов в `public/design-kit/`.
- `docs/PERSONAL_DESIGN_SYSTEM.md` — правила интеграции, безопасности и качества.
- `.agent/plans/0002-personal-design-kit.md` — этап Codex по встраиванию в существующий монтажный пайплайн.

## Начало
1. Сохранить резервную копию проекта / git commit.
2. Распаковать на уровне корня `ai-video-studio`.
3. `node scripts/sync-design-assets.mjs` — создаст `public/design-kit` для включённой графики/SFX. Музыка и шрифты ещё не скачаны.
4. Из корня проекта с установленными зависимостями Remotion: `npx remotion compositions src/design/preview-entry.ts`.
5. Рендер по каждому ID см. `docs/PERSONAL_DESIGN_SYSTEM.md`. Команда требует установленного локально Remotion и работающего браузерного движка.
6. Сверить preview со своими роликами; затем дать Codex план `.agent/plans/0002-personal-design-kit.md`.

**Сначала сверить версии Remotion. Не заменять существующие исходные файлы и не удалять текущий рабочий монтаж.**
