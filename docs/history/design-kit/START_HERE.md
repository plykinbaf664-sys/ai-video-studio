# Начни здесь — AI Video Studio

## Что содержится в архиве
Девять обязательных файлов системы `context-engineer`, дополнительные спецификации, черновая схема edit plan, 20 подробных дизайн-пресетов и ExecPlan для первого реального рендера. **Монтажного приложения и готовых видео внутри нет:** это технический контекст для Codex.

## Куда положить
Распакуй содержимое ZIP **в корень своего проекта** `ai-video-studio` — туда, где будет `package.json`. Все `docs`, `.agent`, `contracts` и `style-presets` должны оказаться рядом с `AGENTS.md`. Твоё расположение папки с проектами может быть любым.

## Что делать в Codex
Открой свою папку `ai-video-studio` и отправь:

> Прочитай `AGENTS.md`, осмотри фактический репозиторий и существующие команды. Используй `.agent/plans/0001-first-render.md` как рабочий план. Реализуй только первый настоящий сквозной рендер из локального `source.mp4` в MP4 со звуком, предпросмотром и проверкой результата. Не выдавай записанные в документации будущие модули и 20 пресетов за уже реализованные. Сверь мои существующие файлы перед изменением; сохрани их. По завершении предоставь фактически запущенные команды, путь к файлу, результаты проверки и открытые вопросы.

Если `source.mp4` отсутствует, Codex должен назвать точный путь, куда его положить, не создавать фиктивное видео.

## Следом, после успешного MP4
Следующий этап — распознавание речи, две временные шкалы и проверяемый смысловой edit plan. Не переходи туда до подтверждённого первого рендера.
