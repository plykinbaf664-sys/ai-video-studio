# Этап 2: первый смысловой монтаж

Визуальная база переработана 2026-10-22: актуальное состояние в docs/BASELINE_VISUAL_QC.md. Ниже сохранена история первого смыслового монтажа; старые кадры и прежние названия компонентов не являются утверждённым качеством дизайна.

## Реализовано

Локальный CPU-ASR (faster-whisper, Whisper small), реальные word timings и confidence. Schema edit-plan 2020-12 проверяется Ajv; source/output time компилируются в кадры без скрытого округления. Склейки внутри слов и неподдерживаемые операции отклоняются. Источник привязан к плану и стенограмме через SHA-256.

SemanticCut сохраняет 6 фрагментов в исходном порядке: 30 секунд вместо 53.75, все 40 распознанных слов. Звук, видео и source caption times находятся под общей Sequence. Акценты используют output time и имеют purpose/evidence. Полный кадр сохраняется без crop.

Текущие решения составлены Codex по расшифровке, а не автономным режиссёром. Внешних медиа-API нет. Полная библиотека style-presets не реализована: работает фиксированное сдержанное оформление.

## Проверки

- Локальная расшифровка реального исходника: 40 слов, 6 реплик, ru.
- Runtime CTranslate2 4.8.3 падал; 4.4.0 подтверждён на CPU Intel Core i3.
- validate:edit: schema, хеш, source/output time и границы слов — passed.
- ESLint/TypeScript — passed; 7 тестов — passed.
- Бандл и CLI compositions построены: SemanticCut 900 кадров / 30 секунд.
- Studio http://localhost:3001/SemanticCut: видео/субтитры загружены, out/semantic-studio.png.
- Просмотрены кадры 30, 180 и 870: начало, субтитры после склейки, финальный акцент; лицо не перекрыто.
- out/semantic-cut.mp4 создан: 30 272 643 байта, 900 кадров, видео 30 с, H.264, AAC 48 kHz. Параметры и полное декодирование — passed; отчёт out/semantic-cut.verification.json.
- Waveform QC — passed: 12 проверок (две на каждом из 6 фрагментов), корреляция 0.99995–0.99998, найденный лаг 0 ms с шагом поиска 1 ms. Это проверка на выборочных окнах, а не доказательство слухового качества всего ролика.

## Команды

npm run transcribe → npm run validate:edit → npm run render:semantic; повторный QC: npm run verify:semantic. После смены источника нужен новый plan; рендер решений не генерирует.

## Ограничения

Транскрипт ASR draft; слова с низкой confidence перечислены в out/semantic-edit-decisions.json. Слуховая редактура и художественная оценка пауз не выполнены. Waveform QC проверяет совпадение исходного звука по клипам, а не правильность расшифровки или качество шутки.
