# Следующий этап: настоящая дизайн-система

## Что есть сейчас

| Источник | Фактическое состояние | Следующая работа |
| --- | --- | --- |
| style-presets/ | 20 JSON с проектными правилами, не 20 исполняемых стилей | Согласовать исполняемый контракт режиссуры и статусы реализации |
| brandbooks/ | Создан проверяемый пустой catalog.json; утверждённых брендбуков не предоставлено | Получить шрифты, палитры, логотипы, запреты, права и правила применения |
| reference-library/ | Создан проверяемый пустой catalog.json; утверждённых образцов нет | Собрать разрешённые примеры и разметить, какие приёмы/таймкоды служат образцом |
| assets/ | Реальный Manrope Variable, SIL OFL 1.1 и asset.json; это временная база | Реестр лицензированных шрифтов, графики, аудио с источниками, хешами и назначением |
| src/design/ | Реальные базовые текстовые компоненты, загрузка шрифта, группировка/измерение/защита от пересечений | Развивать общие профессиональные компоненты под согласованные правила |

Текущее оформление имеет id baseline-unbranded и approvedBrandbook=false. Оно устраняет дефекты базового ролика, не является утверждённым Minimal Premium или брендбуком. Глобального селектора стилей и случайного подбора эффектов нет.

Технический фундамент следующего этапа реализован: DESIGN_LIBRARY_STATUS.md. Исполняемый baseline-контракт находится в style-presets/runtime/, схема — contracts/design-library.schema.json. assets/catalog.json регистрирует реальный шрифт с SHA-256 и лицензией; npm run design:check проверяет зависимости и возможности. Это не утверждение новых стилей. Первые направления для согласования: STYLE_DIRECTION_BRIEF.md.

## Контракт стиля

Следующий контракт должен описывать совместно:

- **Ритм:** правила сохранения дыхания/пауз, длина планов, допустимость и мотивировка склеек.
- **Текст:** смысловые группы, иерархия, длина строки, максимум строк, выделения, правила показа до/после акцентов.
- **Графика:** поддерживаемые типы объяснений и вставок, плотность, purpose/evidence, области исключения.
- **Анимация:** допустимые движения, длительности, амплитуда, easing, причины появления.
- **Звук:** исходный голос, музыкальная политика, допустимые акценты, ducking, лицензии.
- **Переходы:** разрешённые виды и длительности, смысловые условия применения, A/V continuity.
- **Бренд и референсы:** brandbookId, referenceIds, assetIds, версия, права, статус утверждения.
- **Ограничения:** safe areas, лицо/руки/демонстрируемые объекты, число конкурирующих фокусов, поддерживаемые компоненты.

Неподдерживаемые поля не должны молча игнорироваться. Источник остаётся read-only. Факты/цитаты нельзя менять ради пресета. Утверждение стиля и реализация — разные статусы.

## Очерёдность

1. Получить и каталогизировать брендбуки/референсы; не выдавать технические defaults за согласованный дизайн.
2. Согласовать контракт Style + Brandbook + Reference + Asset, доступные возможности и несовместимости.
3. Довести общие компоненты: титр, субтитры, смысловой акцент, поясняющая графика, мотивированный переход, звуковой акцент. Для каждого — ограничения, лицензированные зависимости и визуальные проверки.
4. Реализовать сначала 3 согласованных направления на одном и том же монтажном фрагменте. Оценивать ритм, композицию, графику, звук и движение, а не смену цвета.
5. Провести сравнение и утверждение, затем расширять каталог до 20.

## Приёмка следующего этапа

Каждый реализованный стиль подтверждается MP4 с исходным звуком, контрольными кадрами, версиями правил/ассетов и отчётами двух независимых проверок: технической и визуальной. Переключение стиля меняет режиссуру согласно контракту. Отсутствующие библиотеки и неподдерживаемые возможности видны явно. Автоматическое кадрирование/поиск лица не считается реализованным по ручной проверке одного ролика.
