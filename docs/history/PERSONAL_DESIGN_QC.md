## Фактические изменения

Комплект распределён по архитектуре с сохранением оригинального архива; все 56 manifest-записей проверены. 15 статичных изображений изучены, видео-референсов нет. Подключены настоящие Onest/Inter с OFL и кириллицей, четыре оригинальных WAV и SVG. Четыре присутствующих MP3 сохранены, но исключены из runtime: документы не подтверждают права.

Новый независимый entrypoint и три candidate-контракта используют прежнее монтажное ядро. Основные index/Root, канонический план и расшифровка сохранены. Есть объяснимая рекомендация по цели; AI Director не изображается реализованным. Нормализованные параметры отвечают за типографику, слоты, карточки, движение и допустимые операции.

Editorial — тихая тёмная редакционная карточка, мягкий вход, медная линия на реальной развязке, без добавленного звука. Dynamic — быстрые входы, смысловое выделение и этапы, финальная верхняя схема с историческими цитатами + исходный портрет целиком снизу, один тихий SFX в паузе. Irony — светлая сухая карточка, выдержанная реакция/пауза исходника, минимальный акцент и один тихий SFX после речи.

Использованы три одинаковых диапазона source 0–5 / 7.7–11.6 / 36.9–43 → output 0–5 / 5–8.9 / 8.9–15. Это 15 секунд монтажа из одного видео, не непрерывный диапазон. Макроритм сравнения одинаков, чтобы не смешивать оценку стилей с другой нарезкой.

## Речь и синхронизация

Реальные 22 слова подтверждены повторной локальной транскрибацией общего аудио и каждого финального MP4. Старое раннее начало слова «И» исправлено в personal-копии по фактическому аудио: output 9.4 → 10.22s; каноническая расшифровка не менялась. Демонстрационные реплики не используются. Каждое слово явно сопоставлено с сохранённым source-диапазоном. Один текущий слой речи, не более двух строк, без SRT/дополнительной subtitle track. Две маленькие цитаты схемы являются уже услышанным контекстом и отделены от текущей речи.

Для каждого MP4 реально выполнены: ffprobe, полное декодирование, проверка исходного хеша, все 450 видеокадров против исходных PTS с учётом grade/viewport, 60 непрерывных аудиоблоков по 250ms против исходной нарезки и объявленного SFX, waveform-поиск для всех 22 слов. Максимальный измеренный аудиолаг 0ms; проверка изображения допускает один выходной кадр. Повторный ASR: 0 lexical differences во всех вариантах, тайминги в пределах 350ms. Каждая отрендеренная активная подпись проверяется по DOM на число строк, обрезание и safe slot. Девять контрольных PNG извлечены именно из готовых MP4; до финального рендера также проверены 9 stills и реальный Studio.

Дополнительная проверка нашла AAC sample peaks выше 0 dBFS (источник +0.99dBFS; первые экспорты +0.019dBFS). Звук пересобран непосредственно из исходной дорожки с gain 0.84 (-1.51dB) перед AAC; все видеопакеты сохранены побитно, повторного кодирования изображения нет. После этого заново выполнены полное декодирование, waveform/покадровый QC, ASR и измерение уровней. Финальный audio-levels.json прошёл: сэмплов выше full scale нет. Это проверка sample peaks, не EBU R128/true-peak mastering.

Цветовая коррекция реально применяется только к footage; before/after и измерения в artifacts/personal. Это умеренный source-specific SDR-профиль, не Log/HDR/LUT и не обещание восстановить пересветы. Рабочий алгоритм — COLOR_WORKFLOW.md.

## Предпросмотр и дальнейшая работа

Конкретные места для ручного прослушивания: «я» на 1.24–1.38s и «тоже» на 11.58–12.52s. У повторного ASR там пониженная уверенность, хотя текст совпал и фактические аудиофрагменты сохранены. Это точки проверки распознавания, не доказанные ошибки монтажа.

npm run studio:personal → http://localhost:3002, композиции Personal-editorial / Personal-dynamic / Personal-irony. Галерея с тремя MP4 и девятью кадрами: ../artifacts/personal/comparison.html. Мануал — PERSONAL_WORKFLOW.md.

Ручная проверка: артикуляция, уже попавшая на самый первый кадр записи; фонетические границы ASR и слова с низкой уверенностью (перечислены в artifacts/personal/final-report.json); художественное утверждение типографики/цвета. Метрики не заменяют человеческое прослушивание и эстетическую оценку. Все три стиля остаются candidate, не approved.

Разделение экрана и плоская смысловая схема работают. Настоящие 3D-сцены, библиотека лицензированных иконок и автоматическое skin-isolation/shot-matching пока не реализованы; ближайший шаг — выбрать основной стиль и добавить короткие видео-референсы с отмеченными моментами движения и цвета. Фото подходят для компоновки и типографики.

Дополнительно реально запускались: `node scripts/master-personal-outputs.mjs`, `scripts/check-personal-audio.py`, `node scripts/check-design-preview.mjs`. Последний подтвердил прежний основной Studio и три baseline-кадра; старый 30s MP4 не пересобирался.
