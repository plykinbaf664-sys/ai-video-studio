# Architecture — целевая схема (не аудит реализации)

Актуальное дополнение Personal Design Kit: исполняемые три candidate-контракта в `style-presets/runtime/personal-*.json` → `src/design/personal/runtime.ts` → `PersonalCut`/`PersonalCue`. Отдельный `src/personal-entry.ts` не заменяет основной редактор. Общая нарезка использует существующий `src/director/timeline.ts`; профиль цвета — `src/color/source-grade.ts`. Фактические команды, материалы и ограничения: `docs/PERSONAL_WORKFLOW.md`, цвет: `docs/COLOR_WORKFLOW.md`. Историческая целевая схема ниже не подтверждает остальные будущие модули.

## Статус
Текущий репозиторий недоступен в этом комплекте. Ни один каталог `src/`, пакет, команда или интеграция не считается существующим до проверки Codex. Ниже — **предлагаемое разделение ответственностей**.

## Опорный стек (подтверждённый выбор направления)
- Node.js / TypeScript.
- Remotion / React для программного оформления, анимаций и MP4.
- FFmpeg / ffprobe для анализа и преобразования медиа — после проверки локальной установки.
- Codex для разработки и оркестрации на раннем этапе.
- Транскрибация со словными таймкодами — провайдер и метод уточняются после тестов.
- AI-смысловой анализ — провайдер не выбран; сетевой обмен запрещён по умолчанию до решения о приватности.

## Целевой поток
```text
локальный source.mp4 (+ параметры, референсы)
       |
       v
ingest / probing ----> asset manifest
       |
       v
transcription --------> transcript + word timestamps
       |
       v
semantic director -----> structured edit plan (source/output timeline)
       |
       v
validator (schema / copyright / bounds / timing)
       |
       v
Remotion compositions + licensed assets + optional FFmpeg
       |
       v
preview + MP4 --------> QC report / user review / revision loop
```
Первый этап идёт по укороченному пути: исходник → Remotion → MP4. Компоненты транскрибации и AI на этом этапе не должны изображать работу.

## Предлагаемое владение модулями (пути не созданы)
- `src/ingest/`: чтение медиа, проверки метаданных, извлечение кадров/аудио.
- `src/transcribe/`: word timings, сегменты, подтверждение языка.
- `src/director/`: семантические решения и обоснование монтажных приёмов.
- `src/timeline/`: вычисление EDL и отображение двух временных шкал.
- `src/render/`: сцены, субтитры, анимации, композиции Remotion.
- `src/styles/`: загрузка и валидация конфигураций `style-presets/`.
- `src/qa/`: автоматические проверки и артефакты доказательства.
- `src/cli/`: локальный интерфейс запуска.
Не создавай пустые каталоги только ради соответствия документу: добавляй их с появлением функциональности.

## Направление зависимостей
Domain contracts/edit plan не зависят от React. Director выдаёт **данные**, Renderer их исполняет. Транскрибация не знает о пресетах. Preset не должен напрямую модифицировать исходник. Провайдеры подключаются через адаптеры, чтобы легко заменить их.

## Состояние и побочные эффекты
- Источники: read-only. Рабочие директории рендеров и превью: генерируемые, игнорируются Git.
- `edit-plan` — сериализуемый, валидируемый артефакт; `seed/version` для повторяемости эффекта.
- Все внешние AI/стоковые запросы — в явных адаптерах с конфигурацией согласия, таймаутами и лимитами затрат.
- Превью и финальный MP4 — разные выходные артефакты, нельзя утверждать качество финала по превью.

## Безопасность и устойчивость
Проверять тип и длительность файлов, пути и аргументы исполняемых инструментов. Не запускать произвольные строки через shell с пользовательским вводом; использовать безопасную передачу аргументов. Не отправлять исходники в сторонние сервисы без разрешения. Не копировать лицензированные ассеты без прав. Не коммитить пользовательские видео, ключи, временные рендеры.
