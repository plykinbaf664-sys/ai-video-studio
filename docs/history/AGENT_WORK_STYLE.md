# Agent Work Style — привычки разработки

- **Проверь реальность.** Перед планом смотри текущее дерево, манифест и вывод команд. Не заявляй, что папки или фичи существуют, пока не увидел.
- **Показывай видеодоказательство.** Для монтажной задачи недостаточно компиляции: нужен воспроизводимый MP4 и проверка звука, положения субтитров и тайминга.
- **Сначала смысл, потом спецэффект.** Каждой дорогой вставке и сложной анимации нужна конкретная смысловая функция; если функцию нельзя назвать — эффект убирается.
- **Сохраняй обратимость.** Не изменяй исходник. Генерируй планы и результаты отдельно; все повторяемые настройки храни в сериализуемом виде.
- **Изменения — по краю задачи.** Сохраняй работающие компоненты, не делай несвязанных рефакторингов.
- **Управляй неопределённостью.** Для распознавания, AI и лицензий явно маркируй предположения. Не заменяй реальный вызов заглушкой, выдаваемой за реализацию.
- **Рисковые границы под тест.** Таймкоды, права на ассеты, схемы данных, пользовательские пути и процессы FFmpeg лучше защищать кодовыми проверками, чем длинными правилами.
- **Контекст — прогрессивно.** Открой релевантные разделы, а не весь справочник при каждой мелкой правке.
- **Проверяй влияние.** После точечной правки проверь изменённую часть и один сквозной сценарий при работе с временными шкалами или рендером.
- **Отчёт без иллюзий.** Разделяй «реализовано», «запланировано», «проверено» и «не удалось проверить».
