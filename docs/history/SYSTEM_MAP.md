# System Map — требуемые сквозные сценарии

Personal Design Kit: реальный source → общий 450-кадровый план + 22 слова → три композиции `Personal-editorial/dynamic/irony` → pending MP4 в `.cache/personal/` → полное декодирование + покадровое/аудио-сопоставление + повторное локальное ASR → готовые `out/personal-*.mp4`. Studio — `npm run studio:personal`; подробности в `docs/PERSONAL_WORKFLOW.md`. Это отдельный реализованный путь, будущий Auto Director не подразумевается.

**Статус:** целевые сценарии. Реальные пути и команды Codex должен подтвердить по репозиторию и записать в `docs/VERIFICATION.md`.

## 1. Первый технический рендер (ближайшая задача)
- **Триггер:** файл `public/source.mp4` доступен локально (путь может быть изменён после осмотра проекта).
- **Поток:** проверить медиа → создать корректно кадрированную вертикальную композицию → Remotion Studio → рендер → ffprobe/просмотр.
- **Артефакты:** итоговый MP4, параметры разрешения/fps/длительности, лог команды.
- **Инварианты:** оригинал не трогать; не терять аудио; пропорции не искажать; не утверждать успех без файла.
- **Проверка:** существование, ненулевой размер, проба видеопотока и аудиопотока, ручной просмотр начала/середины/конца.

## 2. Транскрибация и временные шкалы (после первого рендера)
- **Триггер:** проверенный исходник.
- **Поток:** извлечение аудио → транскрипт с таймкодами → редактор склеек → отображение исходных времён в итоговые.
- **Артефакт:** transcript.json + segments в edit plan.
- **Инварианты:** таймкоды в явной шкале, отсутствие отрицательных/перекрывающихся диапазонов, потери слова при склейке контролируются.
- **Проверка:** искусственный пример с удалённой паузой и известным соответствием времени; синхронизация речи в рендере.

## 3. AI Director (проектируемый)
- **Триггер:** транскрипт, опорные кадры, ограничения и пресет.
- **Поток:** разметить смысловые биты → предложить приёмы с целью → валидировать источники/права → edit plan.
- **Артефакт:** JSON, удовлетворяющий `contracts/edit-plan.schema.json`.
- **Инварианты:** нет случайных эффектов и выдуманных фактов; у значимых решений есть причина и привязка к фрагменту.
- **Проверка:** фиксированный небольшой материал, ожидаемые семантические акценты, нулевая ссылка на несуществующий исходник.

## 4. Style Engine (проектируемый)
- **Триггер:** preset ID + intensity + captions/B-roll policy.
- **Поток:** прочитать `style-presets/*.json` → подтвердить существующий renderer → применить ограничения и стиль к сценам.
- **Инварианты:** одна фактическая композиция и единый звуковой характер; конфигурация не заменяет рабочую реализацию.
- **Проверка:** один и тот же исходный фрагмент через 3–4 первоначальных рабочих пресета, затем каталог 20.

## 5. Revision & QC (проектируемый)
- **Триггер:** просьба изменить один момент или неудачная проверка.
- **Поток:** локально изменить edit plan → повторный рендер → проверки → выдача diff и отчёта.
- **Инварианты:** исходник прежний, изменения точечные, сохраняется возможность воспроизведения результата.
- **Проверка:** сменить один текстовый акцент; проверить, что независимые сегменты не изменились.
