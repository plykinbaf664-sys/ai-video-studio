## Прежде чем запускать команды
Этот комплект не имеет доступа к `package.json` и среде Windows пользователя. **Не выдавай примеры за реальные тестовые команды проекта.** Начни с `node --version`, `npm --version`, списка `package.json` scripts, проверки наличия `ffmpeg`/`ffprobe` и фактической структуры Remotion. Внеси реально работающие команды ниже после проверки.

## Лестница проверок
1. **Логика:** проверки временных шкал, нормализации текста и ограничений preset; schema validation для edit plan.
2. **Компоненты:** тесты субтитров, композиции, границ safe area, изменения масштаба без искажения.
3. **Интеграция:** реальный исходник → реальная композиция → MP4 со звуком, воспроизведение начала/середины/конца.
4. **Пользовательская проверка:** визуальный QC читабельности, смысловых акцентов и корректной естественности речи.
5. **Производительность (позже):** повторные рендеры, большие исходники, ограничение диска/памяти, внешние API и восстановление ошибок.

## Обязательные регрессии
- Аудио и кадры после вырезанных пауз синхронны.
- Субтитры в output timeline соответствуют слышимым словам.
- Source и out timeline не смешаны; cut на границе не обрезает слово.
- Цифры и цитаты в графике совпадают с материалом или явно не утверждаются как факт.
- Выход 1080×1920, 30 fps **если именно такие параметры выбраны для задачи**, без растяжения картинки.
- Лицо и титры не обрезаны; оценён safe area под интерфейсы социальных сетей.
- Не теряется исходная дорожка и не клиппирует итоговый звук.
- Переключение пресета меняет поведение композиции, а не только название/цвет.
- Предпросмотр и финальный MP4 согласованы.
