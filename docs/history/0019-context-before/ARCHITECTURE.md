## Сохранённый сравнительный поток

public/source.mp4 → существующий src/director/timeline.ts (границы целых слов, source/output) → scripts/prepare-reference-base.py (один 450-кадровый кэш с source PTS и умеренным SDR-профилем) + scripts/prepare-reference-audio.py (оригинальный голос/реальные MP3/ducking/паузы) → src/design/stages/ReferenceCut.tsx → фактический MP4 → QC.

Видеокэш — производный от неизменённого источника, не демонстрационное видео. Он убирает повторную дорогостоящую коррекцию при сравнении стилей. src/director/scene-direction.ts задаёт явную геометрию/видимость окна по сценам; те же координаты используются для проверки реальных пикселей, с отдельным объявлением полноэкранных графических cutaway.

Единый entrypoint src/index.ts / src/Root.tsx содержит три действующих Reference-композиции и исторические FirstTest/SemanticCut. src/legacy/personal-v1 содержит отклонённый первый визуальный пакет, не определяет новые сцены. Шрифты загружаются локально до измерения текста, без случайной гарнитуры.

## Каталоги и состояние

assets/catalog.json — единственный источник имён/путей/хешей/лицензий. brandbooks/catalog.json и reference-library/catalog.json связывают стили с источниками. style-presets/runtime/personal-*.json содержит staging: действительный renderer, сцены, причины, video reference beats, музыкальную дорожку и огибающую. Baseline имеет отдельные узкие ограничения; 20 корневых описательных пресетов остаются планами.

out/ — только готовые MP4. artifacts/reports/ — отчёты старого ядра, artifacts/reference-edit/ — текущие QC/кадры. artifacts/history/ и artifacts/legacy-out/ сохраняют прошлые данные. .cache/ — восстановимое; public/generated/ — локальные производные для Studio. Никакой очистки пользовательских источников.
