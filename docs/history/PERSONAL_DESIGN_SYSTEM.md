# Персональная дизайн-система: интеграция в AI Video Studio

**Дополнение интеграции:** текущие пути, реальные команды и границы реализации находятся в `docs/PERSONAL_WORKFLOW.md`; текущий отчёт — `artifacts/personal/`. Текст ниже сохранён как исходная спецификация комплекта. Его demo-entry и команды с путями до переноса не использовать для реального монтажа.

## Статус
Предложены 3 стиля с кодом компонентов. **Локальный Remotion-проект не был прочитан и рендер не выполнялся здесь**. Не считать демо утверждённым финальным дизайном, пока не посмотрели на одном и том же **реальном** фрагменте пользователя со звуком.

## Структура
`brandbooks/media/` описывает инвариант личного бренда; `style-presets/personal-*.json` выбирает режиссуру; `reference-library/media/` показывает обоснование; `assets/library/` перечисляет происхождение и использование ассетов; `src/design/` содержит три реальные React-композиции/компонента.

## Разный характер, единый бренд
- Editorial Focus: редакционный крупный тезис + ровная подпись, плавность, немного воздуха.
- Signal Dynamic: активная смысловая подсветка слова, полоска этапа, графическая метка, темп бодрее.
- Dry Irony: спокойный монохром, сухая табличка/плашка, пауза на панчлайне.

## Реальные команды в существующем Remotion-проекте
В корне `ai-video-studio` со всеми уже установленными Remotion-зависимостями:

```cmd
node scripts/sync-design-assets.mjs
npx remotion compositions src/design/preview-entry.ts
npx remotion render src/design/preview-entry.ts AIVS-Editorial out/preview-editorial.mp4
npx remotion render src/design/preview-entry.ts AIVS-Dynamic out/preview-dynamic.mp4
npx remotion render src/design/preview-entry.ts AIVS-Irony out/preview-irony.mp4
```

Превью по умолчанию показывает графическую заглушку, а не видео человека. Чтобы проверить на одном и том же собственном исходнике, Codex должен подключить медиа по `public/source.mp4` или другому реально существующему разрешённому файлу, передать `videoFile: 'source.mp4'` в `defaultProps` трёх compositions и убедиться, что он не накладывает дополнительные титры поверх уже встроенных. Не изменять чужой код без сверки.

**Если Remotion API отличается по версии — адаптировать на фактическую установленную версию, не ломать приложение.** `preview-entry.ts` — отдельная точка входа, существующий `src/index.ts` не заменяется.

## На каком таймкоде применять графику?
Только после анализа расшифровки, семантических якорей и реально звучащего финального аудио. Три демо-сцены сейчас демонстрируют дизайн, а не отвечают за автоматическую нарезку или точную привязку к речи. В основном проекте timeline mapping должен сохранять originSourceStart, originSourceEnd и outputStart; именно с него связывать титры.

## Проверки, обязательные перед приёмкой
1. Аудиофрагмент «Всё решаю сам» (и любая другая реплика) не исчезает, пока субтитр остался.
2. Автоматическая проверка пересечений и дублирования captions.
3. Плашки не обрезаются и не закрывают лицо в выбранном фрагменте.
4. Поддержка длинного и короткого русского текста (цитаты, цифры, дефисы).
5. Повторная транскрипция финального аудио и ручная проверка сомнительных моментов.
6. Проверка лицензий каждого внешнего звука, иконки, шрифта и B-roll.
7. Один и тот же исходник для сравнения трёх вариантов: без подмены смысла.

## Почему не один кадр на стиль
JSON → набор паттернов (заголовок, обычный subtitle, semantic bracket, label, proof visual, outro), а не одна картинка. Компоненты — стартовая реализация трёх паттернов; последующие добавляются после теста реальным материалом.
