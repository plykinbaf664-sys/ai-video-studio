# Рабочие видеообразцы и скриншоты

Уже доступны video/IMG_3320.MP4, IMG_3321.MP4, IMG_3322.MP4 и 15 screenshots. Они зарегистрированы в reference-library/catalog.json и разобраны в docs/REFERENCE_AUDIT.md. reference-index.json из Design Kit описывает только исходные скриншоты; это не второй полный каталог.

Создай подпапки по направлениям и положи локальные MP4/изображения. Для внешнего видео достаточно ссылки: скачивать его ради каталога не нужно. Заполни описание приёма/таймкодов по templates/design/reference-brief.md.

Медиа этой папки исключены из Git. Времена в описании относятся к самому образцу. Видеообразец не становится исходником нашего монтажа и не даёт автоматического разрешения копировать его файлы. Полный порядок: docs/DESIGN_LIBRARY_MANUAL.md.
