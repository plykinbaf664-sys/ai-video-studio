# Рабочий брендбук

Здесь уже находится Personal Design Kit: BRANDBOOK.md, brand.json, palette.json. Каноническая запись — brandbooks/catalog.json; действительные шрифты — assets/catalog.json. Статус draft/candidate не означает утверждения визуального результата пользователем.

Создай подпапку, например my-brand/, и положи PDF, документ или изображения брендбука. Здесь же может лежать заполненный templates/design/brandbook-brief.md. Не переименовывай/не перемещай уже зарегистрированный файл без обновления его записи.

Медиа этой папки исключены из Git. Наличие файла не создаёт брендбук автоматически: зарегистрируй его через npm run design:add -- brandbook ... или сообщи путь Codex. Полный порядок: docs/DESIGN_LIBRARY_MANUAL.md.
